银行 AI 智能体（仿真演示）· 使用说明
========================================

【先确认你拿到的是哪种】
- 便携包（有 runtime 目录）：按下面“便携包”步骤，双击 start.bat 即可。
- 源码/GitHub（只有 backend/frontend/docs，没有 runtime）：不能直接双击 start.bat。
  评委请下载 Release 便携包：
  https://github.com/zzzsama123/dunyu-bank-agent/releases/tag/v1.0-demo
  开发者运行：安装 Python 3.12，进入 backend，执行 python -m bankagent.api；
  语音/语义模型需按 scripts/setup_asr.ps1 准备，源码仓库不含模型。

一、怎么打开（便携包）
--------------------
1. 解压整个压缩包到任意目录（路径含中文也可以）；
2. 双击 start.bat（或 启动.bat）；
3. 等待 20–40 秒，浏览器会自动打开（默认 http://127.0.0.1:8000；端口被占用会自动顺延，以窗口提示为准）

不需要安装 Python、不需要联网、不需要任何 API Key。
内置 Python 3.12、离线中文语音模型（Vosk）与语义模型（BGE）。

二、环境要求
------------
- Windows 10 / 11（64 位）；
- 浏览器：Edge / Chrome；
- 语音输入需要允许麦克风；手机通过局域网 HTTP 打开时浏览器会禁用麦克风，建议在电脑上演示。

三、第一次启动会做什么
----------------------
- 语音模型直接使用包内 runtime\asr\model，不往系统目录写文件；
- 自动创建演示数据库（余额、流水、订阅、贷款、知识库）；
- 以规则模式运行：所有业务、权限、审计、语音功能可用。

演示验证码：123456

四、可以试什么
--------------
- 查账：我这个月钱都去哪了 / 查这个月账单
- 转账：给张三转100（黄色确认）；给房东转3000房租（强验证）
- 订阅：这三个会员我早就不用了
- 办理：我要还房贷 / 做风险测评 / 重置密码
- 知识：转账限额政策是什么（回答带来源、生效日期、版本）
- 提醒：今天有什么提醒
- 语音：点输入框右侧麦克风，说“查这个月账单”
- 设置：右上角齿轮（身份/授权、语音、历史、运营看板）

五、常见问题
------------
- 浏览器没自动打开：手动访问 http://127.0.0.1:8000
- 端口 8000 被占用时启动器会自动换端口，以窗口提示为准；也可先 set BANK_PORT=8010
- Windows 提示“已保护你的电脑”：点“更多信息 → 仍要运行”（只在本机启动服务，不安装东西）
- 想恢复初始数据：关闭黑窗口，删除 backend\data\bank.db，再启动
- 关闭服务：直接关闭黑色命令行窗口

六、说明与边界
--------------
- 本项目是比赛/演示用仿真系统，全部为合成数据，不连接真实银行，不产生真实资金变动；
- 不是生产级银行系统：真实 KYC/活体、核心系统、坐席质检等未接入；
- 完整能力与缺口见 docs/P0_GAP.md；
- 评委操作细则见 docs/JUDGE_GUIDE.md。
