# AI 技术证据链（一页版）

> 作品简介要求写“所用 AI 技术”，这里只写**用了什么、用在哪、为什么**，不堆名词。

## 1. 技术栈与位置

| 层 | 技术 | 代码位置 | 说明 |
|---|---|---|---|
| 意图理解 | 规则 + 语义帧 + 本地示例库 | `nlu.py`、`understanding.py`、`lexicon.py`、`data/exemplars.json` | 确定性优先，可解释、可回归 |
| 语义兜底 | BGE 中文小模型 `bge-small-zh-v1.5`（ONNX int8） | `semantic.py`、`runtime/semantic` | 仅便携版启用；低阈 0.45 / 高置信 0.75；0.45–0.75 先复述确认；CLS pooling + 余弦 |
| 语音识别 | Vosk 中文小模型 | `asr.py`、`runtime/asr/model` | 完全离线；非 Windows 回退浏览器 |
| 语音播报 | 浏览器 speechSynthesis | `frontend/app.js` `speakReply` | 不依赖云服务 |
| 规划 | 规则规划器（默认）；LLM 可选 | `planner.py`、`llm.py` | LLM 只输出候选计划，不持有授权 |
| 安全决策 | 策略引擎（三级权限/限额/强验证） | `policy.py`、`tools.py`、`validator.py` | 最终由规则裁决，模型不能直连核心 |
| 知识 | 本地知识库 + 版本审批 + 可选向量检索 | `knowledge.py`、`data/knowledge.json` | 答案带来源/生效日期/版本；过期下架 |

## 2. 关键参数

- BGE 三档：≥0.75 直接理解；0.45–0.75 复述确认（“我理解你是想…对吗”）；<0.45 回退示例库/澄清；写操作即使高置信也必须走策略确认/强验证；
- 语义层只兜底：账单分析、订阅详情、理财查询、带收款人+金额的转账、提醒；
- 挂失、退订执行、赎回、批量操作**不走语义直执行**；
- 语音/语义模型全部本地，不上传音频与文本；
- 大模型默认关闭，`AGENT_BRAIN=rules`；需 Key 才启用，失败自动回退规则。

## 3. 边界（必须讲清）

- 规则模式是默认交付：**无 Key、离线、可复现**；
- BGE 语义只在便携版 Python 3.12 生效；开发机 3.15 无 onnxruntime 轮子时自动回退；
- LLM 只做“理解/候选计划”，**不做授权、不直接调用工具**；
- 所有资金动作仍走：参数校验 → 策略 → 确认/强验证 → 执行 → 回执 → 哈希链审计。

## 5. 已知限制

- 语义层是阈值匹配，不是大模型推理；跨领域复杂句仍可能澄清；
- 知识检索是关键词 + 向量混合，没有文档解析/重排；
- 未接真实核心、KYC、坐席质检；
- 详细缺口见 `docs/P0_GAP.md`。
