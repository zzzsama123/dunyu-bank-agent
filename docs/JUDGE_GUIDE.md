# 评委使用指南（免安装版）

## 三步打开

1. 解压 `bankagent-portable.zip`（任意目录，路径含中文也可以）；
2. 双击 **`start.bat`**（或 `启动.bat`）；
3. 等 2–5 秒，浏览器自动打开 `http://127.0.0.1:8000`。

**不需要安装 Python、不需要联网、不需要任何 Key。** 内置了 Python 运行时与离线中文语音模型。

## 首次启动会做什么

- 第一次启动会把语音模型复制到 `C:\Users\Public\BankAgent\`（约 65MB，几秒钟），之后不再复制；
- 自动创建演示数据库（余额 12,345.67 元、今日已用 500 元、5 个订阅）；
- 以**规则模式**运行：所有业务与安全能力完整可用。

## 常见问题

| 问题 | 处理 |
|---|---|
| 浏览器没自动打开 | 手动访问 `http://127.0.0.1:8000` |
| 端口 8000 被占用 | 在命令行执行 `set BANK_PORT=8010` 后再运行 `start.bat`，访问 8010 |
| Windows 提示"已保护你的电脑" | 点"更多信息 → 仍要运行"（脚本只在本机启动服务，不安装任何东西） |
| 语音没反应 | 确认浏览器允许麦克风；手机需 HTTPS，建议在电脑上演示 |
| 关闭服务 | 直接关闭那个黑色命令行窗口 |

## 包内结构

```
start.bat / 启动.bat        一键启动
runtime\python\             内置 Python 3.12（含 vosk 依赖）
runtime\asr\model\          离线中文语音模型
backend\                    服务、业务、测试、评测
frontend\                   对话界面 + 功能面板
docs\                       合同、命令、验收、资源说明
scripts\                    启动器、健康检查、模型安装等
```
