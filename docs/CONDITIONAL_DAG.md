# 条件式 DAG 说明

## 支持的语法

```
[查询句，]如果 <条件> 就 <动作> [否则 <动作>]
```

条件支持：

- 支出：`本月/这个月/上月/上个月` + `账单/支出/消费` + `超过/超/大于/高于/低于/少于/不到/不低于/不超过` + 金额；
- 余额：`余额/卡里/账户里` + 比较词 + 金额；
- 多条件：`并且 / 而且 / 同时 / 且` 连接，全部成立才执行 then；
- else：`否则 / 不然`。

## 计划结构

```
n0  analyze_spending / get_accounts   ← 条件查询
n1  get_contacts                      ← 业务前置
n2  quote_transfer
n3  create_transfer                   ← condition: n0.total_cents > 100000
                                        depends_on: n1,n2,n0
```

- `condition` 是节点元数据，引用查询节点的字段；
- 查询节点真实入图，不只是在回复里预计算；
- 动作节点依赖查询节点，拓扑序保证先查后办；
- 策略、确认、强验证、审计仍走原链路；
- `otherwise` 分支不满足时直接执行 else 动作，不生成 then 的确认卡。

## 示例

```
查上个月账单，如果超1000就帮我转500给张三
→ n0 查上月支出 → 条件成立 → 转账确认卡（500）

如果账单超过100000就转500给张三，否则查余额
→ 条件不成立 → 直接回答余额，不生成转账确认卡

如果余额低于1000就提醒我交房租，否则查余额
→ 条件不成立 → 回答余额
```

## 边界

- 不是任意布尔表达式引擎：不支持嵌套 if、循环、跨用户条件、复杂脚本；
- 条件求值只读，不产生资金动作；
- 条件查询节点执行失败时按原执行器失败路径处理；
- 复杂多步业务仍由 planner 的固定模板生成。
