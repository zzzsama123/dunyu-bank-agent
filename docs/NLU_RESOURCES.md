# 中文理解资源与离线落地（不接大模型）

目标：提升"人话"的覆盖率，但**不在运行时依赖任何第三方库或外部 API**。
做法是把公开语料/规则"编译"成词表、正则和测试集，随代码离线运行。

## 参考的公开资源

| 资源 | 用途 | 我们怎么用 |
|---|---|---|
| [SMP2019 中文人机对话 NLU](https://github.com/ygwpz/SMP2019-ECDT-NLU) | 客服场景意图说法 | 参考意图维度与口语表达，扩充同义词与澄清候选 |
| [CrossWOZ](https://openxlab.org.cn/datasets/OpenDataLab/CrossWOZ) | 中文任务型对话（带槽位） | 参考"一句话→槽位"的表达方式，设计改写测试集 |

## 本仓库的实现

`backend/bankagent/normalize.py`：

- **口语词**：瞅瞅→看看、查查→查一下、退了/停掉/关掉→取消、老妈→妈；
- **错别字**：转帐→转账、帐单→账单、云储存→云存储、支负→支付；
- **中文金额**：五百二→520、一千二→1200、一万二→12000、1.2万→12000；
- **转账动词**：给张三打 100 块→给张三转100 块；
- **时间**：上周三→上周、月初→这个月；\n- **精确日期**：今天/昨天/前天/本周 已支持独立区间（不再归到近 7 天）；\n- **同音字**：内置 `data/pinyin.json`，"李那→李娜"可正确匹配收款人。

`backend/bankagent/phonetic.py` + `data/pinyin.json`：同音匹配（姓名/商户），精确匹配失败时兜底。\n\n`backend/bankagent/understanding.py` 增加：

- 来账询问："查查我妈给我的钱 / 我妈这个月转给我多少" → 流水查询（收入方向）；
- 可疑扣费："有没有乱扣费" → 异常识别；
- 分类账单："上个月餐饮花了多少" → 带分类过滤的支出统计。

## 效果与评测

- 24 条口语/错字/金额改写句：规则模式意图命中 **24/24**；
- 评测集从 155 扩到 **187**（意图 84、端到端 23、权限 40、红队 40），全部通过；
- 目标 240 条，剩余 53 条待补（主要是权限边界与红队的变体）。

## 如何继续扩

1. 从开源语料里抽"说法→槽位"，改写成银行业务句；
2. 先跑 `python -m eval.runner` 看是否通过，再决定补规则还是补归一化；
3. 词表加在 `normalize.py`，语义帧加在 `understanding.py`，用例加在 `backend/eval/cases/`。

## 本地语言资源层（lexicon）

除了规则与示例语料，新增一层零依赖的本地资源，专门处理"话不按套路说"：

1. **同义改写**：`bankagent/lexicon.py` 的 `_SYNONYMS`
   - "叫我 / 喊我 / 别忘了 / 到时候" → 提醒
   - "瞅瞅 / 看一眼 / 查查" → 查
   - "不想用了 / 退了 / 取消掉" → 退订
   - "十五号" → "15号"（中文数字日期）
2. **示例语料库**：`bankagent/data/exemplars.json`
   - 每条 = 一句话 + 意图 + 槽位；规则置信度低时用字符二元组相似度匹配；
   - 例如"钱都花哪了""这个会员我不想用了""卡不能用了""给老妈转500"；
   - 扩充只需加 JSON，不改代码。
3. **日期解析**：`_parse_reminder_day`
   - 15号 / 十五号 / 11月15号 / 下个月1号 / 明天 / 后天 / 下周三 / 月底。

## BGE 语义层（便携版内置，可选）

在规则与示例库之上再加一层真正的中文语义匹配：

- 模型：`BAAI/bge-small-zh-v1.5` 的 ONNX int8 版本（约 23MB），CLS pooling + L2 归一化；
- 运行时：onnxruntime + numpy + tokenizers（仅便携版 Python 3.12 内置）；
- 逻辑：`bankagent/semantic.py`，规则/示例库未命中时，计算与 41 条示例句的余弦相似度，阈值 0.62；
- 安全边界：只兜底账单、订阅（仅列详情）、理财（仅查询）、转账（必须已解析收款人+金额）、提醒；
  挂失、退订执行、赎回等资金/不可逆动作**不走语义兜底**，避免"听起来像"就误执行。
- 开发机 Python 3.15 没有 onnxruntime 轮子，自动回退到示例库；便携包内 `/health` 的 `semantic.available` 为 true。
