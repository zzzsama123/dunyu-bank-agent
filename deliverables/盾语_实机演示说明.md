# 盾语 · 实机操作演示说明

视频文件：`盾语_演示视频.mp4`（49 秒，实机界面抽帧录屏，无配音）

录制方式：真实运行 Windows 便携版，打开 `http://127.0.0.1:8010` 后，
用浏览器 DevTools 协议驱动真实界面操作，逐帧抓取页面画面，再用 PowerPoint
按时间轴导出 MP4。不是 PPT 翻页，也不是后期合成的假界面。

演示步骤：
1. 打开新会话，展示规则模式、零 Key、服务在线；
2. 输入「我这个月钱都去哪了」，展示分类、环比、最大一笔；
3. 输入「给张三转100」，展示黄色确认卡，明确"确认后执行"；
4. 点击「确认执行」，展示回执、交易单号、余额；
5. 输入「下个月1号给房东转2500」，展示定时转账只预约、不立即扣款；
6. 打开审计回放，展示策略、确认、执行、账本全链路。

边界：仿真环境，不连接真实银行，不产生真实资金。
