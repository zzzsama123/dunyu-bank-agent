## 1. 作品名称

**盾语 · 银行 AI 智能体（仿真环境）**

## 2. 作品简介（122 字，≤200 字）

盾语是仿真环境下的银行 AI 智能体：规则、语义帧与 BGE 向量兜底理解口语，Vosk 离线语音，条件 DAG 拆解复杂任务；三级权限、确认卡与强验证、哈希链审计确保“模型只提议、不授权”。零 Key 可演示，不连接真实银行、不产生真实资金。

部署步骤：

1. 解压便携包到任意目录；
2. 双击 `start.bat`；
3. 浏览器打开 `http://127.0.0.1:8000`；
4. 设置 → 安全证据，可现场跑 token/金额/审计三种篡改；
5. 设置 → 对话 → API Key，可填 DeepSeek Key 后一键切换大模型；不填则规则模式完整演示。

不连接真实银行核心，不产生真实资金；所有客户、账户、流水、贷款、信用卡、订阅、积分均为合成数据。演示时钟默认固定 2026-10-31（与种子数据同月），设置 `BANK_REAL_CLOCK=1` 可切真实时间。
